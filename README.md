# SkillForge Testimonials Grid

A modern and responsive testimonials section built using HTML5 and CSS3.

## 🚀 Features

- Responsive CSS Grid Layout
- Flexbox-based Card Components
- Glassmorphism Design
- Gradient Background Effects
- Interactive Hover Animations
- Mobile-First Design
- SEO Friendly Markup
- Accessibility Best Practices
- Fully Responsive (Desktop, Tablet, Mobile)

## 🛠 Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Responsive Design

## 📱 Responsive Breakpoints

- Desktop: 4 Columns
- Tablet: 2 Columns
- Mobile: 1 Column

## 🎯 Learning Objectives

This project helped me practice:

- CSS Grid Layout
- Flexbox Alignment
- Positioning Techniques
- Responsive Web Design
- Modern UI Design Principles
- Accessibility and Semantic HTML
